# Variables and Types

A stock tracker stores an item count, a unit price and a product label. C++ asks you to specify types.

```text
int stock = 12;
double price = 4.50;
std::string name = "Cable";
bool available = true;
```

---

## Understand the idea

`int` stores whole numbers, `double` stores floating-point values, `bool` stores true or false, and `std::string` stores text.

---

## Apply it in a real project

A declaration gives a variable a type and a name. Initialize variables when declaring them so they start with a known value. Include `<string>` when using `std::string`.

> **Tip:** Read the example, predict what it does, then try changing one value or instruction.
