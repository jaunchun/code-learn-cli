# Conditions

A game checks whether a player has enough coins to buy an upgrade.

```text
int coins = 30;
if (coins >= 25) {
    std::cout << "Purchased\n";
} else {
    std::cout << "Not enough coins\n";
}
```

---

## Understand the idea

`if` evaluates a condition. If it is true, the first block runs; otherwise an `else` block can run. Braces group statements.

---

## Apply it in a real project

Comparison operators include `==`, `!=`, `<`, `>`, `<=` and `>=`. Use `&&` for logical AND and `||` for logical OR.
