# Your First Repository

You are starting a small project and want to track changes over time. Git records snapshots called commits.

```text
git init
git status
git add README.md
git commit -m "Add project README"
```

---

## Understand the idea

`git init` creates a repository in the current directory. `git status` shows the working tree and staging area. `git add` stages changes for the next commit.

---

## Apply it in a real project

A commit records staged changes with a message. Git has a working tree, staging area and repository history. A commit includes the staged snapshot, not every untracked file automatically.
