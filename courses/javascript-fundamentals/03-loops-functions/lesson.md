# Arrays and Objects

A task app stores several tasks and displays each task's title and completion state.

```text
const tasks = ["Study", "Build", "Test"];
const task = { title: "Study", done: false };
console.log(tasks[0]);
console.log(task.title);
```

---

## Understand the idea

An array stores an ordered collection. Its indexes start at zero. An object stores named properties, commonly written as key-value pairs.

---

## Apply it in a real project

Use `push()` to add an item to an array. Access object properties with dot notation or bracket notation. Arrays and objects are reference values, so assigning them copies the reference.
