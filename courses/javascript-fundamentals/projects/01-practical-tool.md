# Mini Inventory Tracker

## What you'll build

Build a small inventory tracker that displays item names, quantities and stock warnings.

```text
Inventory status
Keyboard: 8
Mouse: 0
Cable: 14
Warning: Mouse is out of stock
```

## Requirements

- Store at least three products and their quantities.
- Display each product and its stock count.
- Show a warning when stock is low.
- Handle an item with zero stock.

---

## Steps

1. Create a small collection of sample data.
2. Print a readable heading and each item.
3. Add a condition for the warning state.
4. Test normal, low and empty values.
5. Refactor repeated output into a helper function if your course has covered functions.

## Stretch goals

- Allow the user to add a product.
- Save inventory data to a JSON file.
- Add a search feature.
