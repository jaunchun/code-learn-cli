# Values and Variables

A web dashboard needs to remember a username, a score and whether a user is online.

```text
const username = "Mira";
let score = 0;
const online = true;
score += 10;
```

---

## Understand the idea

`const` declares a binding that cannot be reassigned. `let` declares one that can. JavaScript values include strings, numbers, booleans, `null` and `undefined`.

---

## Apply it in a real project

`typeof value` reports a value's type. JavaScript uses one `number` type for integers and decimal numbers. Prefer `const` by default and use `let` when reassignment is needed.

> **Tip:** Read the example, predict what it does, then try changing one value or instruction.
