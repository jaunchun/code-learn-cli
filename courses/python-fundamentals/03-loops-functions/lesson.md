# Loops

A scoreboard must display several player positions. Instead of repeating print statements, use a loop.

```text
for position in range(1, 4):
    print(position)
```

---

## Understand the idea

`for` repeats for each item in a sequence. `range(start, stop)` includes start but excludes stop. An optional third argument sets the step.

---

## Apply it in a real project

`while` repeats as long as its condition stays true. Update the state inside the loop so it can eventually stop. `break` exits a loop; `continue` skips to the next iteration.

> **Tip:** Read the example, predict what it does, then try changing one value or instruction.
