# Status Dashboard

## What you'll build

Build a terminal dashboard that summarizes service or game status information.

```text
Inventory status
Keyboard: 8
Mouse: 0
Cable: 14
Warning: Mouse is out of stock
```

## Requirements

- Represent at least three status values.
- Display a readable summary.
- Show a warning for an unhealthy status.
- Keep display logic separate from stored data.

---

## Steps

1. Create a small collection of sample data.
2. Print a readable heading and each item.
3. Add a condition for the warning state.
4. Test normal, low and empty values.
5. Refactor repeated output into a helper function if your course has covered functions.

## Stretch goals

- Read status data from a file.
- Add sorting or filtering.
- Add a summary count.
