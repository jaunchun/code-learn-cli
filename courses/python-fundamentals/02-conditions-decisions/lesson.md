# Conditions and Decisions

A game checks whether a player has enough points to unlock a level. Conditions let a program choose what happens.

```text
score = 75
if score >= 50:
    print("Unlocked")
else:
    print("Locked")
```

---

## Understand the idea

`if` runs a block when its condition is true. `elif` checks another condition and `else` handles the remaining case. Python uses indentation to define each block.

---

## Apply it in a real project

Comparison operators include `==`, `!=`, `>`, `<`, `>=` and `<=`. Combine conditions with `and`, `or` and `not`. A single `=` assigns a value; `==` compares values.
