# Variables and Data Types

A small shop needs to track product names, prices and stock. Python variables give each value a useful name.

```text
product = "Keyboard"
price = 149.99
stock = 12
available = True
```

---

## Understand the idea

Python assigns types automatically: `str` for text, `int` for whole numbers, `float` for decimal numbers and `bool` for True/False. Use `type(value)` to inspect a value.

---

## Apply it in a real project

An online shop displays a product summary. Store a product name and quantity, then print both. F-strings such as `f"{product}: {stock}"` insert values into text.

> **Tip:** Read the example, predict what it does, then try changing one value or instruction.
